## v1 피드백과 반영

| v1 피드백 | v2 반영 |
|---|---|
| 제품·성분 외에 브랜드·효능·태그 등 기준 테이블이 많아 초기 범위보다 크다. | 제품·성분·제품 성분 3개 테이블만 유지했다. 브랜드와 카테고리는 제품 필드로 단순화하고, 마케팅 태그·제품 특성·상품 티어는 제외했다. |
| 추천 테이블이 제품과 느슨하게 연결되고, 가중치·계산 규칙의 저장 범위가 불명확하다. | 완료 설문마다 추천 실행과 결과 항목을 남기며, 규칙 버전·입력·근거만 스냅샷으로 보존한다. 계산식과 가중치 설정은 저장하지 않는다. |
| 비회원 세션만으로는 재방문·회원 전환 전후의 원본 기록을 연결하기 어렵다. | USER·세션·이벤트·동의·식별 확정으로 분리했다. 익명 ID 해시로 재방문을 연결하고 원본 세션·설문·추천은 이동하지 않는다. |
| IP·기기 정보로 같은 사람을 판단할 위험이 있다. | IP HMAC과 최소 클라이언트 힌트는 세션 맥락으로만 저장한다. 인증 또는 검증된 운영 정정 외에는 USER를 병합하지 않는다. |
| 설문 질문·선택지의 변경과 과거 결과 보존 규칙이 없다. | 설문 흐름을 버전으로 관리하고, 시도는 당시 설문 버전을 고정한다. 공개된 설문은 수정하지 않고 새 버전을 만든다. |
